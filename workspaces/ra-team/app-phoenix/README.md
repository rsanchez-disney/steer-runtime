# app-phoenix

> Extends [ra-team](../) — inherits dev-core, dev-python, ops, dev-web, shared rules and context.

App Phoenix sub-team workspace under the Reference Architecture team. Focused on application development using the RA-Block libraries published by [Stark](../stark/).

- **Team**: App Phoenix
- **Profiles**: `dev-core`

## Setup

```bash
koda workspace apply app-phoenix
koda mcp-install
```
