# portal-developer (workspace-local profile)

Astro engineering specialist for the JedAI documentation portal.

## Agents

### portal_developer
Handles all site infrastructure work: pages, layouts, content collections, React islands, build pipeline, and live-data integrations.

**Use when:**
- Adding or restructuring Astro pages and layouts
- Creating reusable components (Astro or React)
- Setting up content collections and schemas
- Configuring `astro.config.mjs` or build tooling
- Debugging build errors, type errors, or broken imports

## Install

This profile is workspace-local — it is installed automatically when you apply the `portal` workspace:

```bash
koda workspace apply portal
```
