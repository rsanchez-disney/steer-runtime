# content-creator (workspace-local profile)

Documentation content specialist for the JedAI platform portal.

## Agents

### content_creator
Writes and maintains all MDX/Markdown documentation: onboarding guides, model catalog, integration tutorials, API reference, and the platform changelog.

**Use when:**
- Writing a new doc page or guide
- Updating the model catalog when a new model is added via LiteLLM
- Adding integration examples (Python, curl, Node.js)
- Writing or updating the platform changelog
- Editing existing content for clarity or accuracy

## Install

This profile is workspace-local — it is installed automatically when you apply the `portal` workspace:

```bash
koda workspace apply portal
```
